# Citadel of Reversal

**최대 4인이 함께 요새를 지키는 협동 2D 덱빌딩 로그라이크**입니다. Unity 6로 만들었습니다.
카드를 모아 덱을 만들고, 친구와 함께 몰려오는 적을 막으며 4개 스테이지를 돌파합니다.

▶ **플레이 (웹, 무료)**
- **itch.io (고화질, 추천):** https://pkjh8920-oss.itch.io/citadel-of-reversal
- **GitHub Pages (가벼운 버전):** https://pkjh8920-oss.github.io/NewDeckRPG_Siege/
  GitHub는 파일 하나가 100MB를 넘으면 안 돼서, 그림과 배경음을 작게 압축한 버전입니다. 게임 내용은 같습니다.

설치 없이 브라우저에서 바로 할 수 있고, 방 코드만 알면 친구와 온라인으로 같이 할 수 있습니다. (두 주소 모두 같은 서버라 서로 같이 할 수 있습니다)

## 주요 특징
- **싱글 / 한 PC 협동 / 온라인 협동 (최대 4인)**
  - 온라인: 방장이 방을 만들면 6자리 방 코드가 나오고, 친구는 코드를 넣어 들어옵니다.
  - 각자 자기 캐릭터만 조작하고, 갈 곳은 투표(갈리면 표 수만큼 확률), 초소는 다수결로 정합니다.
- **4명의 캐릭터**: 직업마다 자원과 플레이 방식이 다릅니다.
  | 캐릭터 | 자원 | 무기 |
  |---|---|---|
  | 카인 | 영혼 | 사신의 낫 |
  | 이그니스 | 홍염 | 불꽃 깃털창 |
  | 제피르 | 마나 | 서리 지팡이 |
  | 실비아 | 탄환 | 황혼의 저격총 |
- **수성(웨이브) 전투**: 1~3스테이지는 칸을 하나씩 나아갑니다. 정체를 모르는 `???` 카드 중에서 고르면 전투나 이벤트가 나오고, 적은 여러 웨이브로 들어옵니다.
- **4스테이지 지도 모드**: 3스테이지 보스를 잡으면 지도를 얻고, 길을 골라 최종 보스 **설계자**에게 갑니다.
- **150장이 넘는 카드, 110개가 넘는 아티팩트**, 포션, 대장간(강화), 상점, 초소, 보물 상자, 피의 제단
- **몬스터 등급**: 일반 / 정예 / 엘리트 / 무리 / 보스. 보스는 스테이지마다 확률로 정해집니다.
- **레벨업과 능력치**(힘·체력·민첩), 상태 이상 16종, 난이도 5단계, 카드·아티팩트 도감, 튜토리얼
- **효과음 51종 + 배경음 12곡**: 장면마다 다른 배경음(보스는 스테이지별), 효과음은 종류별로 음량을 맞췄습니다.
- **이어하기 저장**(싱글): PC는 파일, 웹은 브라우저 저장소에 저장합니다.

## 기술 스택
- **엔진:** Unity 6 (6000.6.7f1), Universal 2D
- **언어:** C# (파일 70개, 약 3만 줄)
- **온라인:** Unity Relay + Netcode for GameObjects (Unity Transport, WebSocket), Unity Lobby
- **빌드:** WebGL (itch.io), Windows

## 설계에서 신경 쓴 점
- **게임 규칙과 화면을 나눴습니다.**
  `Scripts/Battle/Core`는 `UnityEngine`을 쓰지 않는 순수 C# 코드입니다. 전투 계산, 카드 효과, 적 행동, 맵 생성, 투표, 저장 데이터가 여기에 있습니다.
  `Scripts/Battle/View`는 Core의 결과를 화면에 그리는 일만 합니다. 그래서 규칙을 고쳐도 화면 코드를 건드릴 일이 적습니다.
- **온라인은 "같은 명령을 같은 순서로" 방식(락스텝)입니다.**
  - 모든 화면이 같은 seed로 시작하고, 누가 무엇을 하면 그 행동을 짧은 명령 글자(예: `PLAY|0|2|strike|1`)로 방장에게 보냅니다.
  - 방장이 순서를 정해 모두에게 다시 보내면, 모든 화면이 같은 순서로 실행해서 같은 결과가 나옵니다.
  - 게임 상태 전체를 주고받지 않아서 통신량이 아주 적습니다.
- **끊김에 강하게 만들었습니다.**
  - 게임 중에 누가 나가면 나머지는 계속합니다. 나간 사람의 턴은 자동으로 넘기고, 투표·다수결·상점 대기 같은 곳에서는 그 사람을 빼고 셉니다.
  - 같은 방 코드로 다시 들어오면 방장이 지금까지의 명령 기록을 보내 주고, 그걸 화면 연출 없이 다시 계산해서 원래 자리로 돌아옵니다.
- **무료 서버 한도 안에서 돌아가게 했습니다.**
  Unity Lobby로 지금 열린 방 수를 세서, 동시에 최대 10방까지만 열리게 했습니다.
- **밸런스 숫자는 한 파일에 모았습니다.**
  피해량, 확률, 연출 시간, 온라인 설정 같은 숫자는 모두 `GameBalance.cs`에 있습니다. 밸런스를 바꿀 때 이 파일만 보면 됩니다.
- **UI를 코드로 만듭니다.**
  `UIFactory`로 버튼·이미지·배치를 코드에서 만듭니다. 그래서 씬 파일 충돌 없이 여러 명이 동시에 작업할 수 있습니다.
- **웹 빌드 최적화**
  텍스처를 WebGL 전용 압축(DXT5/BC7)으로 바꾸고 밉맵을 껐습니다. 처음 325MB였던 빌드 용량을 크게 줄였습니다.
  에디터 메뉴 `DeckRPG → 웹 화질`로 화질을 한 번에 바꿀 수 있습니다.
  - itch.io용: 모든 그림 BC7 고화질 (약 140MB)
  - 깃허브용: DXT5 + Crunch 압축, 캐릭터·이펙트 해상도를 낮추고 배경음은 웹에서만 음질을 낮춤 → 약 84MB (GitHub 파일 한도 100MB 아래)

## 폴더 구조
```
Assets/
├─ Scripts/
│  ├─ Battle/
│  │  ├─ Core/   게임 규칙 (UnityEngine 없음)
│  │  └─ View/   화면, UI, 연출, 저장, 사운드, 온라인 (NetSession)
│  └─ Editor/    에디터 도구 (웹 화질 전환)
└─ Resources/    그림, 효과, 배경, 아이콘, 소리 (Sound/SFX, Sound/BGM)
```

## 실행 방법
1. Unity Hub에서 **6000.6.7f1** 버전으로 이 프로젝트를 엽니다.
2. 게임 씬을 열고 ▶ Play를 누릅니다. (씬에 `BattleScreen` 컴포넌트가 붙은 오브젝트가 있으면 됩니다)
3. 온라인 멀티까지 시험하려면, 프로젝트를 Unity Cloud 프로젝트에 연결하고 **Relay**와 **Lobby**를 켜야 합니다. 싱글과 한 PC 협동은 연결 없이 됩니다.

## 조작
- 마우스로 카드를 끌어서 대상에게 놓으면 사용합니다. (대상이 없는 카드는 위로 끌어올림)
